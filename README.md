# TagIn

A multi-school student arrival, departure, and transport coordination platform.

## Project status

Foundation setup is in progress. The application is being built incrementally with a React, Vite, and TypeScript frontend and Supabase backend.

## Safety

- Never commit secrets, service-role keys, or private credentials.
- Configure local environment variables using `.env.local`.
- Keep tenant isolation and row-level security enabled for school data.

## Development

The frontend scaffold and implementation instructions will be added in the next foundation commit.
